# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-23

### Added
- **Interactive 3D Hero Scene**: Custom dark-room setup using Three.js & React Three Fiber with mouse-follow rotation, dynamic monitor glowing screens, and procedural lighting.
- **Cinematic Preloader**: Multi-step audio/visual asset preloader with smooth GSAP reveal timeline.
- **Projects Section**: Split-text 3D curtain reveal animations with canvas-generated procedural background cards for featured projects (FinWise, NEONVOID, Workout App, Saanjh).
- **Interactive CRT Terminal Contact Section**: Procedural canvas-rendered terminal interface featuring real-time typing state updates, state-machine boot sequence, Web Audio API click effects, and contact form validation.
- **Usual Suspects & Design Annotations**: Interactive SVG design doodles and inspection markers providing a Figma-inspired visual commentary across sections.
- **Responsive Navigation & Resume Modal**: Integrated PDF download overlay and mobile navigation menu with backdrop blur effects.
